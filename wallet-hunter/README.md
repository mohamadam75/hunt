# Wallet Hunter

A read-only crypto wallet intelligence dashboard.

## V1
- Hyperliquid wallet watchlist
- PnL / ROI / drawdown-oriented metrics
- Wallet scoring
- Alerts for tracked wallets
- No private keys, seed phrases, trading permissions, or automatic order execution

## Roadmap
1. Live Hyperliquid data
2. Historical snapshots and scoring
3. Browser/Telegram notifications
4. Paper copy-trading simulation
5. Optional live copy-trading adapter with explicit risk limits

This is an analytics/monitoring tool, not investment advice.
